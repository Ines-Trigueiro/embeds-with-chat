# Guide: timeline

- A vertical list of events, oldest first unless the journalist says otherwise; it reads
  well on mobile without horizontal scrolling.
- Each event: a date (formatted for the embed's language), a short heading, and one or
  two sentences. Optional image only if the journalist supplied one.
- Use an ordered list (<ol>) so the order is clear to screen readers.
- If there are many events, show the first few and a "Vis flere" / "Show more" button.
- Keep all events in one JavaScript array at the top of the script.
- Never invent dates or events. Use clearly marked placeholders if the journalist hasn't
  given them.
